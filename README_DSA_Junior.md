# DSA Junior C++ - Lộ trình 30 ngày

## Mục tiêu
Học DSA đúng cách, hiểu bản chất, luyện LeetCode theo pattern, chuẩn bị cho phỏng vấn Junior C++.

## 1. Nguyên tắc học
- Học theo pattern, không học rời rạc từng bài.
- Mỗi bài phải trả lời 5 câu:
  1. Đây là bài gì?
  2. Pattern nào phù hợp?
  3. Vì sao đúng?
  4. Độ phức tạp là bao nhiêu?
  5. Có edge case nào đặc biệt không?
- Mỗi ngày làm 2 bài: 1 bài mới + 1 bài review.

## 2. Pattern quan trọng
